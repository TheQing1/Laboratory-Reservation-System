再到根目录 `README.md` 的「界面」小节取消注释即可。

## 拍摄建议

- 分辨率建议 1600×900 以上，浏览器窗口拉满，隐藏书签栏，使用无痕窗口避免个人信息入镜。
- 演示数据用仓库自带的种子数据即可（账号见 README）。
- AI 对话页先发一句「帮我预约电子电工实验室明天 14:00-16:00 用于电路实验，6个人」，
  这样能同时拍到工具调用过程与最终结果。
- GIF 建议控制在 5 MB 以内（可压缩帧率或用 MP4 链接替代）。
